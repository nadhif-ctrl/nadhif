# Pagani - Website Hypercar

Website statis bertema mobil Pagani (Zonda, Huayra, Utopia), dibuat dari template TraveLand (UIdeck / ThemeWagon).

Buka `index.html` di browser untuk melihatnya.

## Catatan
- Gambar di `assets/images/` (hero-area.jpg, about_image.jpg, blog-1..3.jpg) masih gambar bawaan template. Ganti dengan foto Pagani dengan nama file yang sama.
- Lisensi template: lihat `license.txt`.
